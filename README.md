# Steal a Snackling (working title)

Buy wacky collectible **Snacklings** (living snack food with big personalities) off a conveyor belt, place them in
your base where they earn cash every second, protect your base — and sneak into other players' bases to steal
their best ones.

* Design & architecture: [`PLAN.md`](PLAN.md)
* Expensive-to-reverse decisions: [`DECISIONS.md`](DECISIONS.md)
* Economy curve: [`BALANCE.md`](BALANCE.md)

## Setup

You need [Roblox Studio](https://create.roblox.com/) and [Rokit](https://github.com/rojo-rbx/rokit) (the
toolchain manager). Every other tool version is pinned in [`rokit.toml`](rokit.toml).

```sh
# 1. Install Rokit once (see its README for Windows), then the pinned tools:
rokit install            # installs rojo, wally, selene, stylua, lune, luau-lsp

# 2. Install Wally packages (ProfileStore)
wally install            # creates ServerPackages/ (git-ignored)

# 3. Install the Rojo Studio plugin (once)
rojo plugin install
```

### Playtesting in Studio

1. `rojo serve` in the repo root.
2. Open Studio → new **Baseplate** place → Rojo plugin → **Connect**. The whole map is generated by code at
   runtime, so the place itself can stay empty.
3. Game Settings → **Security** → enable *Studio Access to API Services* if you want real DataStore saving in
   Studio (otherwise ProfileStore falls back to a mock store and nothing persists between sessions).
4. Press **Play**.

Alternatively `rojo build -o StealASnackling.rbxl` builds a place file you can open directly.

### Updating a place in Studio straight from GitHub (no Rojo)

[`studio/SyncFromGitHub.luau`](studio/SyncFromGitHub.luau) brings an existing place's code up to date with the
latest `main`, from inside Studio:

1. Game Settings → **Security** → turn on *Allow HTTP Requests* (you can turn it off again afterwards).
2. View → **Command Bar**, paste the whole file, press Enter. The Output window lists what was added and updated,
   and any script that is no longer in the repo (kept unless you set `REMOVE_STALE = true` at the top).
3. Play-test, then **File → Publish to Roblox**. One Undo takes the whole sync back.

It only touches `ReplicatedStorage.Shared`, `ServerScriptService.Server` and `StarterPlayerScripts.Client` (the
same mapping as `default.project.json`); custom models, ProfileStore and the place's settings stay as they are. CI
checks it against Rojo builds of every commit (`tools/syncTest.luau`).

**A private repo:** GitHub only serves its files with a token. Make a fine-grained personal access token (GitHub →
Settings → Developer settings → Personal access tokens → Fine-grained tokens) for this repository only, with
read-only *Contents* access and a short expiry, and paste it between the quotes of `GITHUB_TOKEN` at the top of the
copy you paste into the Command Bar. Never commit it or put it in a script in the place; it only goes to GitHub.

The PR description for each round contains a step-by-step test script (2-player local server for stealing,
Studio test purchases, etc.).

### Before publishing

1. **Game Settings → Places → Max Players = 8, exactly.** It is a Studio setting the code can't change: the map has
   8 bases, one per player, and a 9th player would be kicked with "server full" (DECISIONS.md #14; the server warns in
   the Output when it is higher).
2. **Game Settings → Security → enable Studio Access to API Services** (to test saving/leaderboards in Studio).
3. Game passes and developer products: the first 4 passes and 8 products exist on the Creator Hub and their IDs are
   in `src/shared/Config/Monetization.luau`. Change prices on the Creator Hub, not in code. Server Luck is a paid
   random item (a boost to luck): players whose Roblox policy restricts those (PolicyService) see its card as "Not
   available" and can't buy it, and nothing needs setting up for that (DECISIONS.md #46). **Four newer items are not
   created yet** and stay hidden until they are: see "Store items to create on the Creator Hub" below.
4. Add your UserId to `adminUserIds` in `src/shared/Config/LiveOps.luau`.
5. **Group rewards:** paste your Roblox group's ID into `groupId` in `src/shared/Config/Social.luau`
   (`TODO(owner)`; the number in the group's URL). While it is `0` the group bonus, welcome gift and Join group button
   are off and hidden; the friends bonus works either way.
6. Optional: music and your own sounds in `src/shared/Config/Sounds.luau` (see "Sounds and music" below), models in
   `ReplicatedStorage/CreatureModels`.
7. **What's New:** before each publish, put a note about what changed at the top of
   `src/shared/Config/Updates.luau` (see "Titles, base skins and What's New").
8. **Before the game goes public, make the GitHub repo private** (GitHub → the repo → Settings → General → Danger
   Zone → Change visibility). While it is public anyone can read `src/server/Codes.luau`, so codes you haven't posted
   yet are not secret. The Studio sync script then needs a token: see "Updating a place in Studio straight from
   GitHub" above.

### LiveOps without a code change

* **Planned events:** add an entry to `events` in `src/shared/Config/LiveOps.luau` (Unix times, UTC).
* **No publish needed:** put the same JSON list in the DataStore `LiveOpsConfig`, key `events` (Creator Hub →
  Data Stores manager). Servers re-read it every 5 minutes, e.g.
  `[{"id":"FridayLuck","startsAt":1767312000,"endsAt":1767398400,"luckMultiplier":2,"bannerText":"2x Luck Friday!"}]`
* **Right now, here or every server:** the host panel (next section), or the admin chat commands `/luck 2 30` (2×
  luck for 30 min), `/event <id> [minutes]` (start a configured event now), `/event off [id]` (end events started that
  way), `/announce <text>` (filtered), which always reach every server. In Studio anyone can use them for testing, and
  they only affect that Studio session.
* **Limited-time creatures:** give a creature an `eventId`; it only appears on the belt while that event runs.
* **Event-only mutations:** give a mutation in `src/shared/Config/Mutations.luau` an `eventId` the same way (e.g.
  Halloween's "Haunted"); it only rolls while that event runs.

### Host panel and live events

Admins (`adminUserIds` in `src/shared/Config/LiveOps.luau`) and the owner of a private server get a **🛠️ Host panel**
row in Settings, beside Codes. Nobody else sees it, and the server refuses everything they send. Numbers, limits,
cooldowns and the shout-out rule are in `src/shared/Config/Host.luau` (CI checks them). DECISIONS.md #49 explains the
design.

**Running an admin event (Leo):**

1. Join any live server and open ⚙ Settings → 🛠️ Host panel.
2. Pick the scope at the right of the tabs: **📍 This server**, or **🌍 All servers** (every server runs it once; a
   toast says if it could only run here).
3. Use the tabs:
   * **🗺️ Map**: switch to a map now, start a vote, or turn this server's map rotation off or on.
   * **✨ Modifiers**: pick one, set the minutes (1 to 60), Start; or Stop the one running.
   * **🎁 Belt**: an admin drop. Pick a Snackling (rarest first) and a mutation, then Drop it! It rides the belt with an
     "ADMIN DROP" banner and is bought like any other.
   * **🍀 Boosts**: luck (2x to 6x for 5 to 60 minutes); start or end a configured event (for its own length or 15 min
     to 4 h); **Gift everyone!**: each player gets 1 to 30 minutes of their own income, like a cash pack.
   * **📣 Message**: a banner for everyone, up to 120 characters, filtered by Roblox first.
4. A typical session: post in your group "admin abuse at 7pm", then at 7pm in All servers: 3x luck for 15 minutes,
   Snack Party, a Rainbow Secret drop, then a 5-minute gift to say thanks.

**Rare finds everywhere:** when anyone finds a Secret Snackling, or a Diamond or Rainbow Mythic, the other servers show
"🌍 Bob found a SECRET Gelato Griffin in another server!" (at most one sent per server every 30 s, one shown every
20 s, never during the tutorial). Turn it off with `shoutouts.enabled = false`.

**What a private server's owner gets (in their own server only):**

* **🗺️ Map**: switch to any map (once a minute) and turn rotation off to stay on it, or back on.
* **✨ Modifiers**: start or stop Sugar Rush, Quick Hands, Fortress or Snack Patrol (one every 10 minutes). These are
  the modifiers marked `hostable = true` in `src/shared/Config/Modifiers.luau`. CI refuses to mark any modifier that
  raises luck, mutations or income, cuts prices, speeds up the belt, drops things or unlocks a mutation, so a private
  server is never a better farm than a public one.
* No belt drops, boosts, gifts, messages or All servers.

**Enabling private servers (Creator Hub):** the experience must be public first. Then:

1. Creator Dashboard → your experience → **Audience** → **Access Settings**.
2. Turn on **Allow private servers**.
3. Free: leave **Requires Robux** off. Paid: turn it on and enter the monthly price in Robux.
4. **Save Changes**.

Changing the price later cancels every active private-server subscription, so pick it once. Private servers can't be
combined with paid access. Some players under 13 can't join private servers, depending on their parental controls.

**Testing in Studio:** everyone is an admin there, and All servers stays in your test session (CrossServer never
publishes or listens in Studio). `/hostas owner` shows the owner's panel, `/hostas none` hides the row, and
`/hostas admin` goes back (reopen Settings after each). Offline, `lune run tools/worldsim/host.luau` (in CI) plays every
role and the cross-server messages with a MessagingService stand-in.

### Map themes

The same bases and belt in twenty-three worlds (`src/shared/Config/MapThemes.luau`): Sunny Meadow, Candy Kingdom,
Frosty Peaks, Nacho Dunes, Hot Sauce Volcano, Midnight Market, Coconut Cove, Apple Pie Orchard, Cherry Blossom Garden,
Cookie Moon, Mango Rainforest, Neon Noodle City, Cloud Nine, Sushi Reef, Cocoa Canyon, Cotton Candy Carnival, Pizza
Piazza, Rock Candy Caverns, Lemonade Lagoon, Bubblegum Bayou, Popcorn Drive-In, Tea Party Garden and Pancake Peaks. A
server starts on a random one and changes every 20 minutes
after a 40-second vote in the HUD. Each map sets scenery colours, materials, lighting,
what grows on the tree spots, ten landmarks outside the wall and the weather; gameplay positions never change.

* **Stay on one map:** `rotation.enabled = false` (and `firstMap = "meadow"` for the original look).
* **Tune a map:** edit its palette / lighting / flora / landmarks; CI checks colours, materials, kinds and the part
  budget, and `lune run tools/worldsim/smoke.luau` builds every map offline.
* **A new map:** copy a theme, give it a new id and add the id to `order`. New flora or landmark kinds are built in
  `src/server/Services/ThemeProps.luau` and counted in `src/shared/Logic/MapThemeRules.luau`. Every map needs a
  signature mutation too (CI checks): add one to `src/shared/Config/Mutations.luau` with `mapTheme = "<id>"`.
* **Signature mutations:** each map has one that only rolls while it is up (Honey, Sprinkled, Frozen, Fossil,
  Molten, Moonlit, Pearl, Candy Apple, Blossom, Lunar, Mossy, Cyber, Angelic with its halo, Abyssal, Fudge, Balloon,
  Cheesy, Amethyst, Zesty, Bubblegum, Buttered, Porcelain, Syrupy), named on its vote button and title card. The Globetrotter achievement asks for every map, so its target
  follows the number of maps.
* **Preview offline:** `lune run tools/worldsim/export.luau <id> out.json` writes any map as JSON for a 3D preview.

### Server modifiers

Every 4-8 minutes a server runs a 5-minute twist (`src/shared/Config/Modifiers.luau`): Rush Hour, Clearance Sale,
Golden Hour, Lucky Breeze, Cash Splash, Sugar Rush, Quick Hands, Fortress, Snack Patrol, the rare Snack Party and
Jackpot (double cash), weather (a Thunderstorm with rain, lightning and Electric Snacklings; a Meteor Shower with
shooting stars and Galaxy Snacklings; Toxic Fog with Toxic Snacklings; Northern Lights with an aurora and Aurora
Snacklings; a Heatwave with Toasted Snacklings), drops (a Supply Drop of crates to race for, a Coin Rain, or a Great
Escape: Snacklings break out of the factory and run along the walkways, and whoever catches one keeps it) or a Snack
Attack (giant Snacklings hover over the belt and everyone taps them down together for a share of the reward; the top
hitter wins a Snackling). Change an effect, a name or the schedule there (CI keeps every effect inside `limits`);
`schedule.enabled = false` turns them off and `weight = 0` keeps one for `/mod` only. BALANCE.md "Server modifiers"
has the numbers.

* **A new weather:** a modifier with `weather` (particles), `lighting` (an overlay like a seasonal one) and/or
  `skyEffect` (`lightning`, `meteors`, `aurora`), and a mutation with `modifierId = "<its id>"` (its description
  should name the mutation; CI checks).
* **Thunder:** `world.thunder` in `src/shared/Config/Sounds.luau` is a slowed-down whoosh for now; paste a real
  thunder clap from the sound library there when you find one you like.
* **Drops:** what crates and coins pay, how long crates take to fall and to open, where they land, and how fast and
  how cleverly a runaway runs are in `src/shared/Config/Drops.luau`; how often they come is the modifier's `drops` (CI
  checks both). In Studio, `/runaway` lets one out now and `/runaway here` right beside you.
* **Snack Attack:** the giants' health, tap rate, reach, rewards and how long they stay are in
  `src/shared/Config/Boss.luau` (CI checks it); `/boss` sends one in Studio (`/boss 20` for a quick one).

### First-time tutorial

New players get a four-step tutorial (buy → collect → lock → steal): one short line under the cash, a glowing beam
and a bouncing arrow to what to do next, and $500 when they finish (once per account; Skip pays nothing). Players who
already had progress when it shipped never see it. Steps finish only when the server sees the real action.

* **Tune it:** `src/shared/Config/Tutorial.luau` (reward, steps, when the lock / steal steps move on by themselves);
  the lines are `tutorial*` in `src/shared/Config/Theme.luau`. `enabled = false` turns it off.
* **Analytics:** Creator Hub → Analytics → Funnels → Onboarding follows it (Joined → FirstBeltPurchase → FirstCollect →
  TutorialLock → TutorialComplete → FirstSteal → FirstRebirth); the custom events `tutorial_step` (seconds per step,
  and how it ended) and `tutorial_skipped` (which step) give exact rates. Never renumber those steps once the game is
  live (DECISIONS.md #21).
* **Test it in Studio:** a fresh Studio player (API access off) starts it automatically; `/tutorial` starts it again
  any time.

### Snackling models

Every Snackling is a 3D "living snack" built in code from plain Roblox parts (no meshes or asset ids).

* **The roster:** 80 permanent Snacklings (13 Common, 13 Uncommon, 13 Rare, 12 Epic, 11 Legendary, 10 Mythic and 8
  Secret) plus 16 event ones (four each for Halloween, Winter, Valentine's and Easter, Rare to Mythic). Prices, odds
  and the share of each tier are in BALANCE.md ("The roster").
* **Polished models:** all 96 have one. The first 64 were designed in Claude Design from the prompts in
  `art/snackling-parts/`; the four Winter 2026 Snacklings (`batch-4.json`), the four Valentine's 2027 ones
  (`batch-5.json`), the four Easter 2027 ones (`batch-6.json`) and the 20 permanent ones added in batch 7
  (`batch-7.json`, DECISIONS.md #50) were built by hand in the same format and checked from every side in an offline
  3D preview, next to their tier's other models (`prompt-batch-4.md` to `prompt-batch-7.md` can redo them in Claude
  Design). Imported with `lune run tools/importParts.luau`, which checks them, sizes them and writes
  `src/shared/Config/CreatureParts.luau` (generated: edit a `batch-*.json` and re-run the tool). See DECISIONS.md #28.
* **Recipes (the fallback):** a Snackling without a polished model builds from its recipe in
  `src/shared/Config/CreatureLooks.luau`, which picks a body plan (blob, biped, quadruped, swimmer, tentacled), the food its
body and head are made of (pizza slice, sushi roll, donut, cupcake, burger, pancake stack, bowl...), a face, animal
features (ears, tails, wings, snouts, horns, shells, manes...) and toppings (sprinkles, drips, a cherry...). Every
kind is listed at the top of `src/shared/Logic/CreatureRecipe.luau`.

* **Restyle one:** change its colours, swap a feature or topping, or change `size`, then check it in Studio with
  `/gallery`. CI keeps every model and recipe valid, inside its rarity's part budget (40 Common / Uncommon, 50 Rare /
  Epic, 60 Legendary and up), standing on its feet and narrow enough for the podiums.
* **Faces stay readable:** eyes, mouths and cheeks are never restyled by mutations (Golden, Diamond, Rainbow,
  Haunted, the map and weather ones).
* **They feel alive:** Snacklings near your camera bob, squash and sway on their podiums, and hop along the belt

### Snackdex and daily quests

* **Snackdex** (the 📖 button): every Snackling a player has ever owned, with its mutations. Owning every regular
  Snackling of a rarity pays a one-time reward (sized from steady income) and +3% income forever (all seven tiers:
  +21%). Event Snacklings have their own tab and never block a tier. Tune it in `src/shared/Config/Snackdex.luau`; new
  Snacklings show up by themselves.
* **Daily quests** (the Rewards button, Quests tab): three a day (2 easy + 1 hard), new at UTC midnight; anything
  finished but not claimed by then is paid automatically. Add or tune quests in `src/shared/Config/Quests.luau` (texts:
  `quest*` keys in `Theme.luau`).
* **Analytics:** custom events `snackdex_tier_completed`, `quest_claimed` and `quests_all_done` (DECISIONS.md #24).

* **Creature models:** put a Model named exactly as the creature's `modelName` (see

* **Sounds:** paste asset IDs into `src/shared/Config/Sounds.luau` (see "Sounds and music").
* **The world's look:** lighting, the spawn plaza, trees, the boundary wall and the terrain outside it are data in

* **Mutations on custom models:** a mutation restyles every visible part of the model (material, colour, ...).
  Give a part (e.g. eyes) the attribute `MutationSkip = true` to keep its own look.

### Settings

The gear button at the right end of the top-right row (lock, 👥 Friends, ⚙; under Roblox's own top-left buttons when
its player list fills that corner on computers) opens Music, Sound effects and Reduce effects switches. They apply at
once and are saved per player in the save's `flags` map (`settings_musicOff`, `settings_sfxOff`,
`settings_reduceEffects`; no save-format change). Reduce effects switches off particles, the belt / factory
animations, Bloom and SunRays on that device; client code can read it with `ClientSettings.reduceEffects()` (or the
LocalPlayer attribute `ReduceEffects`). Whatever the setting, lights and particles on podium Snacklings far from the
camera are switched off to save phones the work (`podiumFx` in `src/shared/Config/Gameplay.luau`). Its last row opens 🎨 Style
(see "Titles, base skins and What's New") and 🎟️ Codes, and for admins and a private server's owner also 🛠️ Host
panel (see "Host panel and live events").

### HUD layout (phones first)

The HUD is laid out for a landscape phone (667×375 is the reference) by `src/shared/Logic/ScreenLayout.luau`, and
the game places every HUD element with it (DECISIONS.md #47): the cash pill in Roblox's top bar strip with one band
under it (the tutorial banner, a "Need $X more?" offer, or the event / modifier / luck pills), the lock, Friends and
gear buttons top right, the four feature buttons in a 2×2 grid top left, TAG on the right with the gadget buttons
around it, the map vote at the bottom. Nothing tappable goes in the middle of the screen, where the character and the Buy / Steal prompts are.

* **Moving or adding a HUD element:** give it a size in `ScreenLayout.SIZE` and a place in `ScreenLayout.layout`,
  hand its frame to `HudController.place`, and keep `lune run tools/layoutCheck.luau` green: it checks 640×360,
  667×375 and 844×390 phones, a tablet and a computer window in the busiest states (no overlaps, nothing off screen,
  no button in the play zone or under Roblox's buttons, 44 px touch targets).
* **Text:** HUD text is measured with the game font's real metrics (`src/shared/Logic/TextFit.luau`); the tests keep
  every map name, banner, chip, toast and offer at 12 UI (10 px) or more, so a longer name or banner that would be
  too small fails CI.

### Achievements

### Redeem codes

Players redeem codes from the Settings dialog (🎟️ Codes row). The codes live in `src/server/Codes.luau`, which never
reaches a game client. **They are not secret while the GitHub repo is public:** anyone can read that file there, so
make the repo private before going public (see "Before publishing"). Each works once per account (the save's `flags`
map, `code_<CODE>`; no save-format change); typing is forgiving (any case, spaces around it), and guessing is slowed
to one try every 5 seconds.

* **Add a code:** a new entry keyed by its text in UPPER CASE letters and digits, with a reward: cash sized from the
  player's income (`{ kind = "cash", incomeSeconds = 180, minimum = 1000 }` = 3 minutes of their income, at least

  `startsAt` and `expiresAt` (unix seconds, UTC): before `startsAt` a code answers like an unknown one. Give an event
  code its event's start and end (`src/shared/Config/LiveOps.luau`): CI refuses a code that hands out an event
  Snackling or mutation outside its event. CI checks every code; changing them needs a publish.
